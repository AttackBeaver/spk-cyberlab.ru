Список функций для реализации согласно ТЗ (недостающие и требующие доработки)

✅Интерфейс администратора для сброса пароля пользователя.

Отображение истории выполненных заданий в личном кабинете студента.

Поддержка Markdown/HTML в тексте тем и заданий.

Встраивание изображений и видео в теоретический материал.

Интерактивные симуляции (визуализация шифров, перебор ключей и т.п.).

Песочница для выполнения кода и SQL-запросов (SQL-инъекции, XSS).

Частичный зачёт при проверке заданий (не только 0% или 100%).

Реализация ограничений по времени и количеству попыток для заданий.

Возврат системы голосования (лайки/дизлайки) для мемов, но пользователь может поставить на мем только один лайк или дизлайк.

Обязательное разделение мемов на категории «видео» и «фото» (автоматическое или ручное).

Фильтрация мемов по категориям.

Поиск мемов по названию и автору.

Сортировка мемов (по дате, популярности и т.д.).

Рейтинг авторов мемов (по количеству одобренных мемов).

Графики прогресса студента по курсам (личная статистика).

Сводная таблица по группам для преподавателя (распределение оценок).

Детализация по каждому заданию для преподавателя (среднее время, попытки, сложность).

Экспорт отчётов в CSV для преподавателя.

Импорт списка группы в Excel формате для администратора.

Панель общей статистики для администратора (активность пользователей, технические метрики).

Система уровней (Новичок, Хакер, Архитектор безопасности) на основе достижений.

Полная адаптивность всех страниц (проверка и доработка).

Поддержка светлой и тёмной темы оформления.

Логирование действий пользователей (запись в таблицу Log).

Дополнительные меры безопасности: CSRF-токены, усиление защиты от XSS и SQL-инъекций (хотя Prisma даёт базовую защиту).

Горизонтальное масштабирование.
